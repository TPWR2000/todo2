## Temat projektu
Menedżer Zadań (To-Do List / Task Manager) – aplikacja desktopowa napisana w języku Python do zarządzania zadaniami, ich priorytetami, terminami wykonania oraz statystykami realizacji.

## Opis projektu
Aplikacja pozwala na tworzenie, przeglądanie, edycję, oznaczanie jako ukończone oraz usuwanie zadań, a także filtrowanie po statusie i priorytecie oraz wyszukiwanie po treści. Projekt został podzielony na warstwy (model, repozytorium, serwis biznesowy oraz interfejs użytkownika `tkinter`), co ułatwia utrzymanie czystego kodu i pisanie testów automatycznych.
